Install the main SpecFlow skills first. Then add the bundled worker agents only if you want them.

SpecFlow ships five supporting worker agents in `agents/`:

- `coder` — implementation worker for `301-spec-implementation`, `302-test-implementation`, `401-cleanup`, and `402-test-correction`
- `validator` — validation worker that runs an assigned test/lint/build mode or explicit mode list and reports separate results without modifying code
- `designer` — visual direction worker available to `106-ui-design`, used for the three independent designs in `108-ui-page-design`, and used by UI-affecting `301-spec-implementation` runs
- `reviewer` — read-only worker for `301`'s two independent pre-implementation reviews and the Review role in `900-feedback-loop`
- `decider` — read-only decision-making worker for the Decision Consult in `901-feature-loop`, picking one option from a brief's option set without waiving readiness gates or repair caps

<Callout tone="tip" title="No repo clone required">
  These commands download the installer script directly from GitHub and run it in one step.
</Callout>

<Callout tone="tip" title="Model Configuration">
  The worker agents ship pre-configured with Claude Code model aliases. Edit the installed agent
  files if you want different models.

  **Defaults:**
  - `coder`: `sonnet` (requires high reasoning and coding capability)
  - `validator`: `haiku` (fast and cheap, just runs scripts)
  - `designer`: `opus` (generates one visual direction per call; optional for `106`. `108` requires three independent design subagents for page-design runs; index-only maintenance skips them. `107` has no required designer calls)
  - `reviewer`: `sonnet` (grounded review against explicit criteria)
  - `decider`: `opus` (the highest-stakes calls in a headless `901` run — nothing else double-checks them)
</Callout>

## Claude Code

Global install:

```bash
curl -fsSL https://raw.githubusercontent.com/ajelinek/SpecFlow/main/install/install-agents.sh | sh -s -- --path="$HOME/.claude/agents"
```

Project-local install:

```bash
curl -fsSL https://raw.githubusercontent.com/ajelinek/SpecFlow/main/install/install-agents.sh | sh -s -- --path=/path/to/project/.claude/agents
```

Direct copy to a chosen directory:

```bash
curl -fsSL https://raw.githubusercontent.com/ajelinek/SpecFlow/main/install/install-agents.sh | sh -s -- --path=/path/to/agents-dir
```

Common target directories:

- Project-local: `.claude/agents/`
- User-wide: `~/.claude/agents/`

## Manual Install

If you prefer not to run the installer, download these files and place them in your target agents directory:

- [`coder.md`](https://github.com/ajelinek/SpecFlow/blob/main/agents/coder.md?raw=1)
- [`validator.md`](https://github.com/ajelinek/SpecFlow/blob/main/agents/validator.md?raw=1)
- [`designer.md`](https://github.com/ajelinek/SpecFlow/blob/main/agents/designer.md?raw=1)
- [`reviewer.md`](https://github.com/ajelinek/SpecFlow/blob/main/agents/reviewer.md?raw=1)
- [`decider.md`](https://github.com/ajelinek/SpecFlow/blob/main/agents/decider.md?raw=1)

Example target directories:

- Claude Code global: `~/.claude/agents/`
- Claude Code project-local: `.claude/agents/`

If your setup does not support the model named in one of these files, replace or remove
the `model` field after copying.

## Important Split

- Use `npx skills add ...` for the main SpecFlow install
- Use the `curl ... | sh -s -- --path=...` installer only if you want the optional worker agents
- Edit copied agent files if you want different `model` values

These agents are installed separately, but they are the intended support structure for full
`301`, `302`, `401`, and `402` runs, plus the `900-feedback-loop` and `901-feature-loop`
orchestration loops.
