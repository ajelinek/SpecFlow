## Why the numbers?

The number prefix groups skills into a predictable progression and doubles as prompt shorthand: say `"Use 301 to implement the x feature"` or `"Run 401 on the changes."`

| Grouping | Meaning |
|---|---|
| `100` series | Build shared project context: domain, product, architecture, UX, and feature map |
| `200` series | Define one feature before coding |
| `300` series | Implement substantial changes, or add tests for existing behavior |
| `400` series | Triage failing tests when the fix path is unclear, or run cleanup-only refinement on an already-changed scope |
| `500` series | Quality Assurance: explore a live, running site for defects, and work that backlog toward resolution |
| `900` series | Orchestration: cross-cutting loops that wrap around other skills instead of forming a pipeline phase of their own |

<Callout tone="optional" title="Reference, not a sequence">
  Start with the `100` series when project context is missing. Once it is clear, the core path is `201 → 202 → 301`. Use `108` for page mockups, `401` for source or test cleanup, `302` for tests of existing behavior, and `402` for failing-test triage. `501`/`502` sit outside the per-feature sequence.
</Callout>

<Callout tone="core" title="The 100 series is not just for greenfield work">
  Use it on existing projects too whenever understanding is weak. Better context produces better plans and implementations.
</Callout>

<Callout tone="bonus" title="Bonus does not mean side quest">
  `context-manager` sits outside the feature loop, but a repo often needs its `AGENTS.md` guidance early.
</Callout>

## Install options

Install interactively and choose only the skills you want:

```bash
npx skills add ajelinek/SpecFlow
```

Install the full catalog:

```bash
npx skills add ajelinek/SpecFlow --skill '*'
```

Add `--list` to preview the available skills first.

After installing, run **[`specflow-setup`](../support-skills/specflow-setup/)** to configure the skills, worker agents, and models for your coding tools. To copy the agents by hand, see **[Custom Agents](../getting-started/custom-agents/)**.
